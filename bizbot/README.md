# BizBot — Chatbot IA pour micro-entrepreneurs via WhatsApp

## Vue d'ensemble

BizBot est un assistant intelligent accessible via WhatsApp qui aide les micro-entrepreneurs à gérer leur activité au quotidien : facturation, suivi clients, rappels de paiement, conseils fiscaux simples, et bien plus.

## Pourquoi BizBot ?

- 📱 WhatsApp = l'outil que tout le monde utilise déjà
- 🤖 IA = réponses rapides et personnalisées
- 💰 Abonnement mensuel = revenus récurrents
